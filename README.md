# Anti block rotation

Makes the side-textures of blocks the same. For donutsmp

Minecraft 1.21.8 · Fabric · client-side only (changes only what you see on your own screen).

- Press **Right Shift** (rebindable in Controls) to open the **Onxon client** menu.
- Type anything into Name / Balance / Shards / Kills / Deaths / Playtime. Empty = original.
- `&a`, `&l`, `&c` etc. colour codes work.
- Settings are saved to `config/anti_block_rotation.json`.

## Build
Push to GitHub; the **build** workflow (Actions tab) produces the jar under Artifacts.
Needs Fabric API in your mods folder.
